Chrome 拡張機能・Webユーティリティ開発

日々のWeb作業を快適にする、
シンプルで安全なブラウザ拡張機能

NovaStrikerは、日常のブラウジングや作業効率を高めるGoogle Chrome向け拡張機能を開発・公開しています。すべての拡張機能は外部へのデータ送信を行わず、機能制限なしで無料提供しています。

公開中の拡張機能

Google Chrome ウェブストアにて無料で配信中のソフトウェア一覧です。

Gofile 一括DL

Version 1.0.0 ・ 2026年8月24日更新 ・ 39.31KiB

無料公開中

gofile.ioの共有ページにあるファイルを、フォルダ階層と元のファイル名を保持したまま一括ダウンロードできる非公式ユーティリティ拡張機能です（ファイルをホスト・配信するサービスではなく、ブラウザ上で動作するクライアント側のツールです）。

  • 元のファイル名とサブフォルダ構造をそのまま再現して保存
  • 選択したファイルのみの一括取得・保存先フォルダの柔軟な指定
  • 進捗表示・キャンセル・失敗ファイルの再試行・パスワード解除済みフォルダ対応
  • 外部へのデータ送信なし・ブラウザ内完結で動作
Chrome Web Storeで見る

ヤフオク出品者ブロッカー

Version 1.0.0 ・ 2026年9月7日更新 ・ 26.74KiB

無料公開中

Yahoo!オークションの検索結果や一覧ページから、指定した出品者の商品をワンクリックで非表示にするChrome拡張機能です。不要な検索結果を整理し、目的の出品を探しやすくします。

  • 検索結果の商品からワンクリックで非表示登録・IDやURL直接登録にも対応
  • 「完全に消す」「薄く残す」の2種類の表示モードを切り替え可能
  • 最大2,500件登録・テキストでのバックアップ書き出し／読み込み・Chrome同期対応
  • 外部サーバーとの通信コードなし・設定はブラウザ内にのみ保存

開発支援について

NovaStrikerが公開しているChrome拡張機能はすべて無料で、機能制限なくご利用いただけます。ツールを気に入っていただけた場合のみ、今後の保守・アップデートおよび新規ツール開発の励みとして、任意のチップ（開発支援金）をお送りいただけます。

機能差はありません：支援の有無によって拡張機能の機能や利用制限が変わることはありません。
決済処理について：オンライン決済はStripeの安全な決済基盤（クレジットカード等）を通じて処理されます。
決済前に下記の特定商取引法に基づく表記をご確認いただけます。

開発支援のご利用方法

開発支援は各Chrome拡張機能内の支援メニューから利用できます。拡張機能の設定画面や完了画面に設置された案内リンクから、任意の金額（300円〜・税込）をお選びいただけます。

対象ソフトウェア：Gofile 一括DL / ヤフオク出品者ブロッカー
決済方式：Stripe を利用した都度のクレジットカード決済（追加手数料なし）
提供形態：無料公開ソフトウェアへの任意チップ（追加機能の販売やサブスクリプションではありません）

プライバシーポリシー

1. 拡張機能における情報の取り扱い

当方が公開するChrome拡張機能（「Gofile 一括DL」「ヤフオク出品者ブロッカー」等）は、利用者の検索キーワード、閲覧履歴、アカウント情報、ダウンロード履歴等の個人情報を外部サーバーへ送信・収集することは一切ありません。設定情報および登録リストは、利用者のブラウザ内（Chromeストレージ領域）にのみ保存されます。解析タグや広告SDKも組み込んでいません。

2. 開発支援（決済）時の情報の取り扱い

任意の開発支援決済をご利用いただく場合、クレジットカード情報等の決済データはStripe, Inc.によって暗号化・処理され、当方がカード番号等を直接取得・保持することはありません。決済に伴い取得するメールアドレス・氏名等は、決済確認およびお問い合わせ対応の目的にのみ利用します。

3. お問い合わせ

本ポリシーに関するお問い合わせは、novastriker@nova-striker.com までご連絡ください。
